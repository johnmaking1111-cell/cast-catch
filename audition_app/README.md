# 🎭 CastCatch - 배우 오디션 모아보기 (MVP)

영화, 드라마, 연극, 뮤지컬, 광고 오디션 공고를 웹에서 자동 수집·정제하여 배우들에게 최적화된 모바일 뷰어 및 알림 형태로 제공하는 경량 서비스입니다.

---

## 📁 프로젝트 구조

```text
audition_app/
├── data_store.py      # 데이터 저장소 및 샘플 공고 관리
├── collector.py       # 크롤링 및 LLM 기반 공고 파싱 모듈
├── notifier.py        # 카카오톡/텔레그램 일일 브리핑 메시지 생성기
├── server.py          # 경량 REST API 및 모바일 웹 서버 (포트 8080)
├── auditions.json     # 공고 데이터베이스 (JSON 기반)
└── static/
    └── index.html     # 모바일 최적화 반응형 웹 프론트엔드 (Tailwind CSS)
```

---

## 🚀 빠른 실행 방법

```bash
# 1. 앱 서버 실행 (모바일 웹 뷰어 + API)
python3 server.py

# 2. 브라우저에서 접속
# http://localhost:8080
```

---

## 🛠️ 핵심 기능 요약

1. **장르별 원터치 필터**: [전체] [🎬 영화] [📺 드라마] [🎭 연극] [🎶 뮤지컬] [📸 광고/CF]
2. **조건 검색 & 필터링**: 성별, 마감임박순(D-Day), 최신등록순, 실시간 텍스트 검색
3. **배우 편의 기능**:
   - 마감일 카운트다운 배지 (`D-Day`, `D-3`, `상시채용` 등)
   - 원문 공고 바로가기 (아웃링크)
   - 접수처 이메일 원터치 복사
   - 관심 공고 북마크(찜하기)
4. **일일 카카오톡/텔레그램 브리핑**: `notifier.py`를 통해 매일 아침 등록된 신규 오디션 요약 발송 연동 가능
